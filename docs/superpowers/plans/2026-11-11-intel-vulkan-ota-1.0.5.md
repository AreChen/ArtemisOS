# Intel 集显 Vulkan 与 1.0.5 OTA 实施计划

> 面向 Agent：在当前分支实施，保留未提交的既有工作。用户已要求将前一轮验证通过的 Intel 路径产品化并发布 OTA。

**目标：** 提供可保存的 Intel 集显 Vulkan 选项，并让 1.0.4 完整安装和 OTA 升级用户均能保留数据升级。

**架构：** 复用 37.3.9 的 ANGLE ES/Vulkan 路径，新增 `vulkan_intel` 配置。通过已启用 Intel HD/UHD/Iris 的 Windows 设备完整名称选择 ANGLE 设备，启动后验证实际 GLES renderer；无设备、名称不匹配或 CPU 回退均报错，不静默切换。只改变子进程环境，不修改全局显卡设置。

**决策：** 本次沿用已验证的 Intel 精确名称方案；其他厂商和新型 Intel Arc 集显不作已验证支持声明。现有渲染偏好及新安装的硬件 OpenGL 默认值保留。配置中同时保留通用 Vulkan 实验选项和软件模式。本机正式启动改为用户要求的 Intel 模式。

**交付：** 只发布共同基线上的四个根脚本及版本文件，不包含 SDK、镜像、数据、凭据或签名私钥。1.0.4 的 VBS 和迁移 sidecar 有来源差异，本次保持不变。

## 步骤与验收

- [x] 新增失败测试：配置保存、设备筛选、精确 GPU 校验、继承环境隔离、软件快捷方式覆盖。
- [x] 修改 settings/configure/launch/initialize，安装器保留新增偏好；运行新增及相关原有测试。
- [x] 关闭只读实验实例，备份并部署本机脚本，以正式启动器验证 Intel 真实渲染和持久数据实例启动。
- [x] 从干净的 1.0.4 基线构建签名补丁；分别用完整安装和 OTA 基线应用，验证版本、VBS、数据和原偏好。
- [x] 独立审查发布内容，上传 OpenList；匿名客户端读回签名清单及小型对象，并确认 1.0.5 无更新标记。
- [x] 保存发布证据与用户启用步骤，报告实际补丁大小及验证范围。

## 审查重点

- 禁用核显、无 Intel、设备名不符时明确停止本次实例；不能声称已选 Intel。
- 软件渲染快捷方式不受已保存的 Intel 选项影响；继承 ANGLE 首选设备不得污染其他模式。
- 不改写 1.0.4 历史更新，不修改其 SDK 硬链接，不删除用户数据。
- 两种 1.0.4 来源都必须满足全部被修改路径的 base hash。
- 小补丁必须让旧的 `launch-current.ps1` 正常透传新启动器；签名和中断恢复继续生效。
