# 1.0.6 原生显示前端发布计划

用户已于 2026-11-12 授权制作完整安装包、验证旧用户 OTA 并上传现有 OpenList。

- [x] 冻结已经通过用户验收的前端、运行组件和启动脚本。
- [x] 补齐新增显示组件的许可、构建记录和可等价下载的对应源码资料包。
- [x] 使用两条真实 1.0.5 发行基线验证同一签名 OTA，保留配置和 AVD 数据。
- [x] 构建 1.0.6 全新安装 EXE，并在隔离标准账户中安装核验。
- [x] 上传源码资料、完整包和更新对象，最后切换签名更新清单并检查匿名客户端。
- [x] 保存发行基线和证据，更新本机版本标识并提供下载链接。

Ruling: 沿用当前项目和 codex/hardware-vulkan 分支，不整理或提交无关修改。

Ruling: 不更新 SDK/系统镜像，不改变已保存渲染偏好，不清理用户数据。

Ruling: 对应源码独立放在与二进制相同的 OpenList 公开分发位置，安装目录保留下载说明和完整通知，避免用户每次 OTA 强制下载开发源码。

Ruling: 保留两条历史来源的 VBS 和迁移 sidecar，签名补丁只覆盖具有共同精确旧哈希的文件和新增文件。

Ruling: 全量安装器继续用于新安装；已有安装通过 OTA 更新，不能要求用户卸载并丢失原数据。

当前状态：1.0.6 已发布，完整包与 OTA 均匿名读回通过；本机保留数据升级并启动完成。详见 docs/history/release-1.0.6-native-frontend.md。
