# ArtemisOS 15 1.0.1：默认软件渲染补丁

发布日期：2026-11-03。已发布到现有 OpenList OTA 通道；1.0.0 客户端可检查并安装，1.0.1 有已签名的无更新标记。本次为启动配置补丁，不包含系统镜像或完整安装包。

- 从 1.0.0 首次升级后，正常启动采用 `-gpu swiftshader`。初次使用时将旧 `graphics` 设置迁移为 `swiftshader`；其他配置和 Android 数据不改动。用户之后仍可在“配置”的“图形渲染”中选择硬件或其他模式，不会被再次覆盖。
- 发生变更时原配置备份到安装目录的 `data/preferences.before-swiftshader-1.0.1.ini`，`data/graphics-swiftshader-1.0.1.flag` 是一次性迁移标记。迁移在版本文件提交为 1.0.1 后执行，并支持中断重试。
- 补丁只有 `configure.ps1`、`settings.ps1`、`version.ini` 三个文件，文件内容合计 20,478 字节；清单与签名另占少量空间。此次**不替换**启动脚本、SDK 或镜像。
- 已核对 `releases/1.0.0` 和 `releases/1.0.0-sd-fixed` 的上述三个基线文件相同，尽管两个版本的 `launch.ps1` 不同，因而该补丁可覆盖这两个已知基线。不要用其中一个基线直接生成会覆盖另一个版本 `launch.ps1` 的后续补丁。安装文件被另行修改时，现有更新器会拒绝不匹配的基线。
- 已使用两个基线的隔离副本，从线上公开更新地址实际检查、验证签名、下载并应用补丁；验证目标版本无更新、正常启动解析出的渲染模式、原配置备份、Android 数据保留、手动切换硬件。单独验证了旧版本门控、中断重试、并发迁移及不同旧配置。
- 本机 `E:\ArtemisOS15` 检查到可更新至 1.0.1，但发布时模拟器仍在运行，未中断运行并未替用户安装。1.0.0 的完整安装包本身仍使用其原来的默认配置，安装后需通过 OTA 升级。

此次切换可减少对宿主显卡驱动的依赖，但它本身不能证明用户报告的长时间内存增长已修复；仍需在受影响电脑用相同直播场景观察内存趋势。软件渲染可能提高 CPU 占用或降低播放流畅度。
