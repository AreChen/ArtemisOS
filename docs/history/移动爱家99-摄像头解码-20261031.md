# 移动爱家 99.0.0 摄像头播放排查

- 现象：摄像头直播停在连接中或提示网络重试。日志显示视频帧数据已到达播放器，但画面没有成功输出。
- 首次失败：2304×1296 的 HEVC 流使用 `c2.goldfish.hevc.decoder`；启动后该解码器报告 `0xe/14`，播放器后续反复调用已释放的解码器。
- 复现对照：关闭模拟器 `HardwareDecoder` 特性并冷启动后，同一路流使用 `c2.android.hevc.decoder`，日志持续出现成功绘制的帧。用户确认画面显示且流畅。
- 成本和范围：该特性同时影响模拟器的 AVC、HEVC 和 VPx 硬件视频解码。软件解码可能增加 CPU 占用；图形渲染模式是另一项设置。默认启用视频兼容模式，用户可以在配置中关闭并重启。
- 该结果确认当前摄像头和模拟器组合的解码兼容问题，不代表排除了其他摄像头或网络环境下的连接故障。记录不包含摄像头地址、画面或登录信息。
