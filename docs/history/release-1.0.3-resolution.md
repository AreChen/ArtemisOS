# ArtemisOS 15 1.0.3：分辨率预设

- OTA 从 1.0.2 升级到 1.0.3，仅更新 `configure.ps1`、`settings.ps1` 和 `version.ini`，不更新模拟器运行时或系统镜像。
- 新增竖屏 9:16：720 × 1280（320 dpi）、1080 × 1920（480 dpi）。
- 新增横屏 16:9：1280 × 720（320 dpi）、1920 × 1080（480 dpi）。
- 保留原有的 720 × 1600、900 × 2000 和 1080 × 2400 选项。升级不会改变当前设置；修改后需要重启模拟器。
- 不替换 `launch.ps1`：原始 1.0.0 与 SD 卡修复版的该文件不同，保留各自版本才能同时兼容，并避免覆盖 SD 卡修复。

2026-11-04 验证记录：

1. `tests/display-graphics.ps1` 验证新旧预设、密度、配置持久化及其他设置不被改变；`tests/graphics-default-migration.ps1` 通过。
2. 使用隔离 AVD 和现有 Windows 启动器，逐一启动四个新预设，ADB 查询的物理尺寸、密度及显示矩形均符合预期；另对 1280 × 720 检查了实际 Windows 模拟器窗口。
3. `tests/resolution-ota-release.ps1` 分别以原始版和 SD 卡修复版的启动文件模拟 1.0.2 升级，确认两个版本均可安装且启动文件、设置及模拟用户数据保持不变。
4. 本机由签名补丁从 1.0.2 升级到 1.0.3，模拟器自动重启并完成 Android 启动，设置文件前后哈希一致，原有 720 × 1600 显示及 SwiftShader 选择保持不变。
5. 已发布至 OpenList，逐个读回校验上传文件；使用 1.0.2 客户端代码从服务器检查更新、验证签名并下载三个补丁对象，1.0.3 检查到已是最新版本。

1.0.0 和 1.0.1 的旧更新程序可能无法自动重启；这些用户可先使用已发布的 1.0.2 OTA 修复工具，再检查 1.0.3。新预设不代表对所有应用的横屏布局或长时间播放性能已经验证。
