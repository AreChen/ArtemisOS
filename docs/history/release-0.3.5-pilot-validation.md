# ArtemisOS 0.3.5：OpenList 与镜像精简试验

本记录区分更新通道、镜像内容、压缩包体积和安装后磁盘占用。试验在 Windows x86_64 上进行；实验镜像和隔离 AVD 不代表所有电脑或应用均通过兼容性验证。

## OpenList 更新

- Windows 更新器使用 HTTPS 读取 OpenList 只读分享的直读地址，并继续校验签名、清单、路径、已安装文件基线和内容哈希。服务器的不存在文件返回 HTTP 500，因而使用已签名的同版本空清单表示暂无更新；其他服务错误不是“暂无更新”。
- 对隔离安装做过云端对象上传、下载、更新、重新检查和中断后重试，旧数据保持不变。
- 当前电脑原有安装已通过安卓内更新界面从 0.3.4 更新到 0.3.5，更新后自动重启、应用列表一致、检查更新显示暂无更新。此更新只改变小的版本文件，**没有替换原有系统镜像**。
- 0.3.4 用户需先安装一次连接组件。发布脚本交互式取得受限账户凭据；客户端不含账户密码，分享地址本身是可读取更新内容的凭证。发布操作先对象后目标版本标记，最后来源版本清单和签名；后两者并非原子写入，切换间可能短暂检查失败。
- 更新按变化文件下载完整文件；不是 Android 分区级 OTA、二进制差分或断点续传。直接更新当前候选系统镜像将下载约 3.33 GiB，仍需实现压缩或差分。同版本可能对应不同系统镜像，不能直接向其发布唯一基线的镜像更新。
- 该服务器在关闭访客 API 的条件下，已知路径的测试文件仍可通过 `/d/` 匿名下载；仅验证了单个自行创建的测试文件，应由服务器管理员审计直链访问规则和其他目录权限。

## 独立镜像候选

基于当前 Android 15 Google APIs x86_64 镜像的独立副本，移除了 Google 搜索、设备智能相关组件、数字健康、Android Auto stub 和 Markup。保留 Google Play 服务、WebView、输入法、语音服务和 ARM64 转译相关文件。ext4 释放约 418 MiB；同一 product 分区以 XZ 快速模式压缩的测试减少约 143 MiB，**此数据不是最终安装包的大小差值**。

原始系统分区镜像基线曾出现首次冷启动后包管理器 `Broken pipe`；重启后包管理、x86_64/ARM64 JNI、本地 WebView JavaScript、Google Play 服务基础绑定、DNS 和 TCP 443 探针可用。另一次全新低配置冷启动经历了 291 秒、系统服务重启，设置 Activity 当时返回 `PermissionPolicyInternal` 空指针，试验未通过；该时段 E 盘负载较高，成因尚未确认。这些记录不能视作首次冷启动或精简候选的完全通过。

首启日志显示，模拟器的 `-change-locale zh-CN` 可能在首次报告启动完成后触发 framework 重启；不能仅凭首次 `boot_completed=1` 判定语言和系统服务已就绪。产品初始化等待时间由 300 秒延长至 900 秒，等待期间仍会在就绪后立即继续、在模拟器关闭后退出；低性能设备的实际首启耗时仍需测量。

随后在 C 盘独立 AVD 对照中，未修改镜像基线通过了两次冷启动、包管理与设置 Activity 稳定性、x86_64/ARM64 JNI、WebView、Google Play 服务基础绑定、DNS 和 TCP、简体中文以及上海时区冒烟检查。两次启动均观察到 system_server 启动次数增加，重启原因仍未断言。详细结果见 `build/image-refine-20261031/baseline-c-1-evidence/test-results.json`。

精简候选在相同 C 盘隔离设置下通过了同一组检查，两次启动后均确认应用服务稳定、简体中文和上海时区；六个目标系统包均不在包清单中。system_server 启动次数变化与基线相同，原因仍待确认。两次启动到 `boot_completed` 的宿主计时约为 57 秒和 18 秒，仅是单次冒烟记录，并非跨设备性能基准。详细结果见 `build/image-refine-20261031/candidate-c-1-evidence/test-results.json`。这不能证明所有应用或 GMS 登录均兼容。

## NTFS 磁盘占用

在可独占的独立候选镜像单链接副本上，安装流程使用的原地稀疏化工具前后两次 SHA-256 一致：`ab633cc0504a61c6006cd39d2b371dff8e341f0176e70384597692d7d90a2752`。文件逻辑长度始终为 3,576,692,736 字节；实际 NTFS 分配由 3,576,692,736 降为 2,312,044,544 字节，节省 1,264,648,192 字节（约 1,206 MiB）。不同文件系统和磁盘状态不保证同样结果。

该稀疏副本的独立 AVD 已冷启动一次（约 240 秒，宿主负载较高，不能用作性能结论），包管理器和设置 Activity 可用；启动后镜像哈希及实际分配仍与启动前一致。读取的语言属性为空，故这次不能确认简体中文默认值或宣称候选通过全部验收。

独立小型安装器夹具验证了新目录稀疏化、既有镜像不被转换、哈希错误导致非零退出、未完成目录不能直接重试，以及原卸载注册和快捷方式恢复。稀疏化工具另行验证了硬链接、锁定、标记缺失、错误哈希、中断和重试，PowerShell 5.1 与 7 均通过。受限线程令牌下的文件操作通过；独立标准用户账户上的完整安装尚待复测。

## 完整试用安装包

- `dist/ArtemisOS15-Offline-Installer-0.3.5-pilot.exe` 为 1,232,523,021 字节（约 1.15 GiB），SHA-256 为 `091e1fb478057407a0a985b0d48919bc6a09e1f4732d04b1753ec9956ed8fbbd`。相较原 1,928,750,267 字节安装包减少 36.1%，相较上一版 1,563,813,636 字节安装包减少 21.2%。两项比较均是实际安装包，而非 product 分区压缩量。
- 在 Windows 11 64 位版本 10.0.26300 上，用 `tests/pilot-installer-isolation.ps1` 将实际安装包安装到独立的全新目录：镜像哈希、OpenList 默认地址、0.3.5 版本及已签名的无更新标记均通过检查；系统镜像实际分配 2,312,044,544 字节，节省 1,264,648,192 字节。
- 全新实例以独立 AVD 和端口 5568 冷启动，初始化状态标记确认语言和网络设置完成，实际语言为 `zh-CN`、时区为 `Asia/Shanghai`。测试后检查原有卸载登记与七个快捷方式已逐字节恢复，当前使用的实例未被覆盖。自动化脚本已修正启动器后台等待及 ADB 设备尚未出现时的处理，修正后完整验证通过。安装及初始化日志保存在本地 `build/image-refine-20261031/installer-final-test/`；测试安装目录已清理。
- 这是 Google APIs 镜像的定制副本，并非从 AOSP 源码构建。单机验证不等于其他 Windows 版本、低性能电脑、全部应用及图形硬件均已验证。

## 许可证

试运行的云端更新只包含很小的版本文件，没有上传 Google 镜像或 SDK。向其他用户分发或上传 Google 镜像、模拟器运行时和相关驱动前，仍需分别确认适用的许可与再分发条件。
