# 移动爱家 99.0.0 启动超时排查

2026-10-31，当前模拟器为 Android 15 x86_64、中档配置。用户反馈应用间歇性打不开。

- Android 记录到一次进程启动超时（ANR）；当时主线程停留在系统加载应用类的阶段，没有捕获到应用自身的 Java 崩溃。
- 同一时段模拟器的 Windows 进程优先级为最低，后台正在压缩完整安装包。将模拟器进程调回正常优先级并暂停打包后，两次冷启动的首个页面约在 1.1～1.3 秒出现，应用随后进入主页。
- 0.3.3 为模拟器进程和其 QEMU 子进程恢复正常优先级。更新重启后确认两个进程均为正常优先级；后台再次打包时，开机后的首次应用启动页面耗时约 30.6 秒，再次冷启动约 1.8 秒。
- 这些观察说明调度和首次加载可能有影响，但同时存在多项变量，不能据此证明单一根因或保证问题已完全消失。未清除应用数据或登录信息。
