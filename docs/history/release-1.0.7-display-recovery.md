## 内容与大小

修复 Sunshine 串流、虚拟显示器、Windows 分辨率或 DPI 切换后的视频冻结、旧画面只占左上角以及错误的“已连接”状态。显示消息合并防抖并重算布局；明确的连续帧更新错误触发显示端重连，每轮与每分钟均有次数上限。正常恢复包含约 2 秒等待及视频连接初始化，用户已确认真实 Sunshine 切换可自动恢复。

自动恢复只重建 scrcpy 显示连接，不重启 Android；不改变 GPU 偏好。修复并发手动重连、关闭、OTA 交接、慢失败和旧进程回调的边界。故障证据及 17 场景回归见 [调查记录](sunshine-display-recovery-20261112.md)。

## 旧版如何升级

服务端保留逐版本清单及所引用对象，现有客户端每次只安装一跳：

```text
1.0.2 → 1.0.3 → 1.0.4 → 1.0.5 → 1.0.6 → 1.0.7
1.0.4 → 1.0.5 → 1.0.6 → 1.0.7
```

用户每次在 Android“ArtemisOS 更新”中检查并安装，等待正常重启完成，再检查下一版。不需要卸载或清空数据，不是自动一键跨过所有中间版本。

1.0.3 → 1.0.4 需要重启入口中的 `update/launch-current.ps1` 完成启动器迁移后再进行下一跳；连续离线测试若指定 `-NoRestart`，需显式运行 `-NoLaunch -Headless`。不能跳过迁移或提前替换其 completed 事务。

这些路径适用于正式发行文件及正常用户配置；本地手工修改的受更新文件仍会因严格旧哈希不匹配而拒绝更新。不能把拒绝校验改为强制覆盖。1.0.0/1.0.1 的旧退出问题另见 [1.0.2 修复工具说明](release-1.0.2-ota-restart.md)。
