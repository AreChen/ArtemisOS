# 正式安装包的临时用户验收

此工具检查 **指定的实际安装包** 的全新安装，不会启动 Android 实例。它使用新建的标准本地账号和独立的 HKCU，并把程序安装到新建的 `build\isolated-final-<随机值>\work\install`。这不是 Windows Sandbox：标准用户可能仍能读取机器上允许普通用户访问的共享内容，应只用于可信的安装包。

先审阅脚本并在管理员权限的 **64 位 Windows PowerShell 5.1** 中运行只读预检（将四个路径替换为经核对的发布材料）：

```powershell
rtk proxy powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File .\tests\isolated-final-install.ps1 `
  -Installer '<正式安装包.exe>' `
  -ExpectedImage '<已确认的 system.img>' `
  -ExpectedServer '<已确认的更新服务器配置文件>' `
  -ExpectedTrustedKey '<已确认的更新公钥.xml>'
```

没有 `-Execute` 时，只检查前提并计算输入哈希；不会创建账号、运行安装器或访问更新服务器。确认输入无误后在同一命令末尾加 `-Execute` 才开始实际验收。默认最长等待 120 分钟，可通过 `-TimeoutMinutes` 指定 5–180 分钟。安装前会复制一份安装包到测试目录，因此需要足够的空闲空间。账号设定为 4 小时后过期。

脚本检查产品和卸载登记版本、Emulator 包及程序的 `37.3.6` 版本、系统镜像 SHA-256、首次安装标记、实际自动渲染偏好、更新配置及公钥 SHA-256，再调用安装后客户端，从实际配置的服务器获取并验证已签名的 1.0.0 同版无更新清单。在线检查异常只记录执行步骤，避免在输出中泄漏服务器地址。测试不等于启动、显示、虚拟化、图形驱动、Android 应用兼容性或升级路径验证。

脚本会在创建账号前写入非秘密的 `account-journal.json`，创建后记录 `account-sid.txt`。临时密码通过加密随机数生成，仅保存在内存中，不写入文件或进程参数。子进程被放入退出时终止的 Windows Job；只有临时账户 SID、用户资料目录、注册表和运行目录检查通过后才执行安装。机器级存在相同 AppId、Windows 不允许本地登录或不能加入 Job 时会停止。

正常结束和可捕获异常时，脚本先终止子进程组、禁用临时账号，再检查配置目录，最后尝试删除账号。只有新账号 SID、非系统配置、未加载、路径位于用户资料根目录的预期直接子目录、目录不曾存在、未与其他用户资料重叠、无路径重解析点且 ACL 包含临时 SID 时，才调用 Windows 用户资料管理接口删除该配置。验收目录、安装副本及 `cleanup-status.json` 会保留以便审阅；这包含安装包本身部署的更新配置，请按内部保密要求处理，不要公开分享该目录。

**故障边界：** 强制终止控制进程、断电、系统故障或策略拒绝时，不能保证 `finally` 会执行，也无法承诺账户立即删除。账号的到期时间和日志便于人工恢复；到期不等于终止现有登录会话。若 `cleanup-status.json` 报错，或该文件缺失，管理员应先查看该运行目录的日志，在本地账号管理中核对随机账号名称、描述标记和 SID，再确认账号已禁用；确认用户资料的 SID、占用状态与路径均仅属于该账号之后，通过 Windows 用户资料管理界面处理残留。若任何一项无法确认，应保留而不是删除。Job 不能替代隔离虚拟机，也不能保证抵御恶意安装程序。

离线小型检查（不会创建账号或运行安装器）：

```powershell
rtk proxy powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File .\tests\isolated-install-guards.test.ps1
```

## 后续升级验收

升级安装器定稿后，可在同一个临时账户先用正式 0.3.6 包安装到 fixture，写入可识别的测试数据和配置，使用本机回环 HTTP 仓库提供签名过的 0.3.6 → 1.0.0 补丁，再运行待测引导程序。应分别断言注册表版本和安装路径、卸载记录、数据和配置的内容及哈希、补丁验签、升级后的启动入口，以及失败/中断后的状态。然后使用另一个全新临时账户执行新装验收，避免前一次的 HKCU 和用户资料影响结果。当前脚本只实现新装验收，不声称验证了这条升级链。
